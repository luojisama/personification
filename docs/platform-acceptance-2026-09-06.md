## 已实现的行为

### 人格、表情与记忆

- 普通、YAML、Agent、主动消息、TTS 和表情共用管理员核心人格。动态情绪、关系、群风格与记忆不能改写核心，平台不硬编码真寻。最终归属与人格审阅最多改写一次并复核，失败静默，无固定补救句。
- 表情总开关与本地、QQ 收藏、QQ 推荐、协议表情开关覆盖候选、工具、标记、入队和最终发送。来源由程序保留，不能经模型改标签绕过；排队后配置变化在执行前生效。
- 收藏要求实际视觉证据、人格审美、表达用途和已有收藏判断。未知分类、视觉失败、缺字段或非法返回均跳过，按内容摘要、人格版本和归属缓存。发送仍重新核对本轮语境，并发送审阅过的受控图片字节。
- 记忆召回使用当前可信 Bot、平台、会话和授权范围，先过滤再排序。群聊不复用私聊权限，模型提供的 ID 不能扩大范围；关闭记忆时聊天召回停止，管理台查看权与模型召回权分离。
- 宫殿点击分区后读取真实分页明细；补齐搜索、状态与来源。内部状态、向量索引或宫殿缺数据时显示未知或未配置。保留历史数据，不清库、不批量重写画像。

### 受控禁言

- 默认关闭；仅功能已开启、群已授权、适配器支持、Bot 当前为管理员且目标可管理时开放，执行前重新查询权限。
- 同一群、对象和冲突必须有两次不同用户轮次、确认送达的提醒。分段、草稿、其它插件输出和未知交付不计数；第二次提醒后仍须有新的持续冒犯及同一互动引起的当前负面状态，经独立语义核验。
- 事件默认 30 分钟有效，和解、结束或过期后失效；只接受非布尔的 1～20 整数分钟，处罚后重新累计提醒，同一事件不叠加。
- 专用账本持久化幂等与交付状态，未知结果只查询、不重放。WebUI 展示证据、提醒次数、状态及现场权限复核后的解除入口，通用工具不能绕过。

### 重试、媒体、转发与消息归属

- 每个 Provider 最多首次请求加三次瞬态重试，适用于超时、网络中断、408/409/425/429 和 5xx。默认次数四，保留显式单次配置；关闭 SDK 内部传输重试，防止次数相乘。
- 基础退避 1/2/4 秒，429 的 Retry-After 有上限；请求、退避、换路由、YAML 转换及工具续轮共用本轮绝对截止时间。取消或预算耗尽即停止。400/401/403 不原样反复提交；明确请求兼容修正、过期凭据刷新另有有限边界。社交发送与禁言不属于 Provider 重试。
- Trace `c909e13adab64e21` 的备用模型已完成语义与生成，却被最终审阅固定 8 秒窗口截断；现消费本轮剩余预算。Trace `bbdda5c3f5ff4c21` 的 400 原因尚需生产脱敏诊断，不能宣称重试解决请求形态错误。
- 成功路由保留在本轮共享状态，工具续轮严格绑定。新增诊断不记录原始 Provider 正文、媒体 URL、Base64、凭据或隐藏推理。
- 四类模型请求与工具续轮覆盖 OpenAI Chat Completions、Responses、Anthropic Messages、Gemini Native。1/2/4/8 图回归断言实际载荷、顺序、重复表示去重、不同消息归属、部分失败及选中历史图。
- 音视频复用既有受控媒体实现。Gemini Native 小型 MP3/WAV/FLAC、MP4/WebM 使用 inlineData；官方 Google 端点保留 Files 上传/等待/清理，第三方端点不自动假定支持 Files。显式 `openai_gemini_inline` 是管理员声明的网关音视频扩展，不依据域名或模型名猜测支持。
- inline 读文件前核对聚合大小，构造后核对完整 UTF-8 JSON 的 20 MiB 上限；准备失败、取消仍清理已上传临时文件。文件签名、传输成功和内容理解分别核验。
- OneBot v11 与可选 Satori 进入共享回复链，身份使用平台/Bot 命名空间。真实可选适配器 1.3.0 回归文本、多图、引用、群范围和自身回声抑制；QQ 专有能力保持独立边界。
- 嵌套转发文字作为不可信引用，保留节点作者、转发者、外层消息和媒体顺序；图片受控下载并冻结字节后进入同轮投影。最多 8 次图片准备尝试、20 个节点/分段，服从共同截止时间。
- 人类引用 Bot 原话仍是人类触发，引用内容保持 Bot 归属。普通/YAML 回放检查实际输入、审阅及外发；自身回显不产生新的用户消息。转发内无法解析的本地/不透明媒体、尚未解包的内嵌音视频保持未知，不伪造理解。

### 能力探测

- 手动操作立即返回持久化 `operation_id`，具有排队、运行、完成、失败、取消和中断状态，以及详情、分页历史和取消；重启不残留永久运行中。
- 分开保存 `last_verified` 与 `latest_attempt`。网络、鉴权、超时不抹掉历史支持结论；显示名、角色、温度、超时和密钥轮换不清空证据。实际端点、协议、模型或编码变化进入新请求指纹，旧历史保留。
- 前端捕获操作失败、显示原因，SSE 与活跃任务有界轮询配合，终态停止，刷新可恢复活跃任务。
- 插件默认每天 Asia/Shanghai **03:30** 加少量错峰运行，与手动任务共享串行租约和去重；错过最多补一次，不重放积压。单项默认 45 秒、每路由 480 秒，历史默认 90 天，最近有效证据继续保留。修改调度时间后重启生效。
- 合成工具执行器不作社交写入，每条目标路由独立验证，不用备用成功证明目标能力。日志保留安全错误类别、HTTP 状态、实际阶段耗时、数量和传输/内容验证。

## 用户执行的一次性生产验收

1. 备份服务器当前版本、配置、数据库并记录回滚版本；更新源码并重启 NoneBot。只使用 OneBot 不需安装 Satori，使用 Satori 则加载相应可选适配器。
2. 查看启动日志、健康状态、探测任务恢复。确认每日默认 Asia/Shanghai 03:30 符合预期，旧运行任务不永久挂起；调度时间修改后重启。
3. 对实际使用的每条供应商/模型运行内置合成探测，分别核验文本、工具、图片、音频及视频。检查操作 ID、进度、历史、取消、失败分类与最近有效验证保留；回答错误不能算内容能力通过。
4. 检查当前人格、表情总开关、QQ 推荐来源、记忆范围和禁言授权。禁言默认关闭，先核对账本和权限，不执行真实禁言作为上线测试。
5. 由用户选择授权环境的实际对话：Bot 发言后群友短回复、引用 Bot、嵌套转发、多图与第二张/比较前两张、普通表情接梗与明确识图。核对实际图片数、归属、最终审阅和确认送达写入；失败应静默。
6. 点击记忆宫殿分区，检查明细；对一次确认送达对话检查持久化、模型选择召回、权限过滤和实际采用。本地通过不证明服务器存量索引已正常。
7. 查看下一每日窗口历史，确认逐路由去重、无积压重放，依据脱敏 Trace 和实际回复确认恢复。反馈 Trace ID、阶段/错误类别、HTTP 状态和媒体数量即可，不附凭据、媒体传输地址或 Provider 原始错误正文。
