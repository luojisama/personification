## 基线待验证问题

1. 原回放脚本只生成 metadata fallback plan，不能测真实回复自然度。
2. 群聊问句检测参与改写及静默，需以有用追问/机械抛问的成对案例分辨误伤。

以上问题已通过实际调用链审计和隔离回归复现；当前在实施有界修复。它们不能代替真实生成对照，尚未通过质量发布门槛。

## 实施与基线更新（2026-09-20）

开发工具提交 `7330a21`、`1443aab`、`9f4cc2e` 已推送并由 VPS Git 拉取，生产回复逻辑仍保持原版本。评测已走实际普通处理器及普通→YAML 交接，使用独立数据库、真实 MemoryStore、捕获 Bot 和合成回执；没有调用真实 QQ 发送接口。

评测修复包括服务器非敏感行为配置快照、HTTP 状态分类、连续失败自动停止、事件与记忆平台/Bot 身份对齐、盲评反序、保留集独立均值和元数据剥离。语料仍为群私各40、开发60/保留20。媒体占位资产仅验证传输，不计入内容质量覆盖；工具、空间互动、完整记忆更新及其它缺失 fixtures 仍明确阻断。

当前核心候选：

- 普通/YAML 共用的文本清洗保留自然口语，不按问号或固定词语否决；风格交给既有最终语义审阅，不增加常驻评分 Agent。
- 默认人格描述自然、友善、有分寸；用户已配置人格不被覆盖。
- YAML Agent 复用普通路径的作用域召回和第二阶段记忆相关性闸门，候选记忆不直接写进可信人格提示。
- 空间文风处理共享整轮预算，最多一次；可以保留原文，后续证据、人格和来源审阅继续执行。
- 多轮评测按确认送达回调写入 Bot 历史，YAML 默认评测模板显式包含最近历史与当前消息。Agent 检索查询由历史派生，必须作为不可信资料传递，不能再次提升为系统指令。

真实基线再次运行时，上游先多次返回 HTTP 503，随后恢复部分案例；最近一次在 `g07-correction` 发生取消并停止。累计预扣请求 **135/1500**（含失败和取消，不退款）；这不是成功响应数，未配置费用，费用未知。
