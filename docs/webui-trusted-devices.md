# WebUI 信任设备

验证码登录时可选择“信任此设备”。已登录用户也可在设备页为当前浏览器开启信任。未持有有效信任凭证的新浏览器仍必须接收管理员验证码；浏览器名称、UA 或 IP 相同不会获得登录权限。

信任凭证保存在浏览器的 HttpOnly、SameSite=Strict Cookie 中，服务端 KV 只保存随机凭证的 SHA-256 摘要。正常会话仍为七天；会话失效后，页面调用同源恢复接口，重新签发会话和 CSRF 凭证，无需再次收验证码。信任凭证有效期为365天，成功恢复时续期，支持插件重启后的持久化恢复。删除浏览器 Cookie、使用无痕窗口或信任超过有效期后需要重新验证。

信任设备只允许在 HTTPS 或本机连接下启用。反向代理应保留浏览器 Host，并从可信内网代理传递协议信息；普通公开 HTTP 连接不能启用信任。公共或共享设备可取消勾选。

设备页显示受信任设备，并允许撤销。撤销信任、撤销关联设备或移除管理员权限会阻止后续恢复，关联会话也会失效。显式退出登录会撤销当前信任和清除 Cookie；即使七天会话已经过期，也可凭当前浏览器的信任凭证和同源证明完成退出。重新验证码登录会替换该浏览器旧的信任凭证，避免遗留授权。

旧版本仅按 UA 登记的信任记录不能用于自动登录，列表将其标记为旧记录或无效记录。信任设备无需额外的第三方身份框架，复用现有持久化存储、管理员 ACL、验证码 challenge、会话、CSRF 和设备撤销机制。

接口使用 `POST /api/auth/refresh` 恢复，不接受请求体中的管理员身份。有效会话的管理动作继续验证 CSRF。恢复入口校验同源 Origin/Referer；浏览器未提供这两者时，需要同源 Fetch Metadata 和 `X-Personification-Refresh: 1`。接口与列表不会返回明文信任凭证。

设计参考：[OWASP Session Management Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)（2026-10-02读取，随机会话凭证、HttpOnly、SameSite、会话更新与服务端失效原则）。365天有效期是本项目面向个人管理员设备的产品选择，不是OWASP规定的默认值。
